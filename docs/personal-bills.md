# 用多维表格保存个人账单

建议字段：交易日期、类型（收入/支出/转账/退款）、金额分（整数）、币种、账户、分类、商户、备注、来源、来源交易号、关联原交易号。

金额以整数分保存，展示时除以 100，避免二进制小数误差。不同币种分别统计。转账不计入消费，退款关联原交易，保留原始记录。

导入过程：

1. 从支付平台自行导出账单，保留原文件备份。
2. 解析 CSV/Excel，统一日期和金额单位。
3. 用「来源 + 来源交易号」搜索已有记录，过滤重复后批量创建。
4. 查询创建结果并核对笔数、币种、总金额；记录失败项后单独处理。

多维表格不提供这里所需的数据库唯一约束或跨多表账务事务保证。去重查询与写入之间仍有并发窗口；同一批导入应串行执行，不能盲目重试整批写入。严格会计账本应另设具备事务和约束的存储。

可向 ChatGPT 这样提问：

> 在我的测试多维表格中新建一张「账单」表，金额按整数分存储。先展示字段方案，再导入我提供的示例数据；导入后核对总笔数和金额。

表容量与 API 配额取决于自己的飞书套餐和权限，使用前核对控制台。示例不包含任何真实个人账单。
